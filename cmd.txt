Camera calibration — command cheat-sheet
Camera: Arducam B0495 (USB3 2.3MP). YUYV only (no MJPG/H.264): 1920x1200 (15/30/50 fps) or 960x600 (15/30/60/80 fps).
Other sizes (e.g. 640x480) are NOT supported by the camera — see "640x480" at the bottom.

One-time: attach USB camera to WSL

# Windows PowerShell (admin)
winget install usbipd
usbipd list                          # find BUSID, e.g. 2-3
usbipd bind --busid 2-3              # once per device

# every plug-in / reboot (use a USB3 port + cable, else low fps / fails at 1920x1200)
usbipd attach --wsl --busid 2-3
usbipd detach --wsl --busid 2-3      # give it back to Windows when done
# camera vanished (/dev/video* gone)? -> detach + attach again (unplug/replug if needed)

# WSL
sudo modprobe uvcvideo
ls /dev/video*                       # usually /dev/video0 (+video1 = metadata, not usable)
# after a reconnect it can come back as /dev/video4, video6, ... -> use the LOWER number of the pair
# in every command below, or restart the container to get /dev/video0 back

Container lifecycle

cd ~/Projects/camera_calibration
docker compose build                 # only after editing Dockerfile
docker compose up -d                 # start container "camcal"
docker compose exec ros bash         # open a shell (repeat for more terminals)
docker compose down                  # stop (also clears stuck drivers / stale nodes)
(Or ad-hoc: docker compose run --rm ros, then docker exec -it <name> bash for a 2nd shell.)

Inside the container

v4l2-ctl -d /dev/video0 --list-formats-ext                # supported formats/fps
v4l2-ctl -d /dev/video0 -l                                # controls (brightness, gain, exposure)

# ONLY ONE camera driver at a time! A 2nd usb_cam (or the script while a manual driver runs)
# fails with "Device or resource busy" / "terminate called after throwing an instance of 'char*'"
# or gives a black calibrator window. Check / clean up:
ros2 node list                                            # must show /usb_cam only once
pkill usb_cam_node                                        # stop all drivers (pkill -9 if stuck)

# terminal 1 — camera driver (pick ONE resolution)
ros2 run usb_cam usb_cam_node_exe --ros-args \
  -p video_device:=/dev/video0 -p pixel_format:=yuyv2rgb \
  -p image_width:=960 -p image_height:=600 -p framerate:=30.0 \
  -p brightness:=0
#   full res: -p image_width:=1920 -p image_height:=1200
# brightness:=0 because usb_cam's default (50) nearly maxes this camera's -64..64 range -> overexposed.
# Type the command cleanly: a stray ^C in "brightness:=0^C" makes it a string -> InvalidParameterTypeException.

# terminal 2 — check / view
ros2 topic hz /image_raw                                  # no output = no driver publishing
ros2 topic echo /image_raw --field width --once           # confirm the resolution actually applied
ros2 run image_view image_view --ros-args -r image:=/image_raw

# terminal 2 — calibrate (8x6 inner corners, 24 mm squares — measure your print!)
ros2 run camera_calibration cameracalibrator \
  --size 8x6 --square 0.024 \
  --ros-args -r image:=/image_raw -r camera/set_camera_info:=/usb_cam/set_camera_info
# left_camera/right_camera "not found", /left /right QoS warnings, XDG_RUNTIME_DIR: harmless (stereo checks)
# window stays black = no images -> check terminal 1 / "ros2 topic hz /image_raw"

# → move board until CALIBRATE is green → CALIBRATE → SAVE → q. Result in /tmp/calibrationdata.tar.gz
# save per resolution (RES=960x600 or 1920x1200):
RES=960x600
cp /tmp/calibrationdata.tar.gz /work/calib/calibrationdata_$RES.tar.gz
tar -xzf /tmp/calibrationdata.tar.gz -O ost.yaml > /work/calib/cam_$RES.yaml

Helpers (scripts/) — the script starts its OWN driver, so stop any manual one first

scripts/calib_live.sh 8x6 0.024 /dev/video0 960x600       # driver + calibrator + save calib/cam_960x600.yaml
scripts/calib_live.sh 8x6 0.024 /dev/video0 1920x1200     # same at full res -> calib/cam_1920x1200.yaml
scripts/calib_from_images.sh 8x6 0.024                    # calibrate from photos in images/

Source workspace

cd /work/ros2_ws
colcon build --packages-up-to camera_calibration --symlink-install
source install/setup.bash            # auto-sourced in new shells
ros2 pkg prefix camera_calibration   # → /work/ros2_ws/install/...

Reuse the calibration later

# calib/cam_960x600.yaml, calib/cam_1920x1200.yaml (camera_name: default_cam)
# width/height must match the yaml; camera_name must match the name inside it, else a mismatch warning
ros2 run usb_cam usb_cam_node_exe --ros-args -p video_device:=/dev/video0 -p pixel_format:=yuyv2rgb \
  -p image_width:=960 -p image_height:=600 -p brightness:=0 \
  -p camera_name:=default_cam -p camera_info_url:=file:///work/calib/cam_960x600.yaml
ros2 topic echo /camera_info --once   # K/D should be the calibrated values

Compressed images (done in software — the camera itself only sends raw YUYV)

ros2 topic list | grep compressed                         # /image_raw/compressed (JPEG), plugins preinstalled
ros2 topic hz /image_raw/compressed
ros2 param set /usb_cam image_raw.jpeg_quality 80         # lower = smaller
# saves network/rosbag bandwidth, NOT USB bandwidth
